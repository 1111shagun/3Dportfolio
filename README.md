## ⚙️ How to Run Locally

Follow these simple steps to explore the project on your computer.

1. Download or clone this repository.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open the folder in your preferred code editor, such as Visual Studio Code.
4. Open `index.html` in your browser, or use the VS Code Live Server extension.

**That's it!** Your portfolio is ready to explore. 🎉
